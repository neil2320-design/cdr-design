CDR 迴路設計手冊：從 MM-PD 到 VCO 的相位追蹤

這是對應 CDR 方塊圖的完整設計推導：相位偵測器如何產生誤差、 二階特徵方程式如何決定 Kp / Ki、響應驗證如何確認模型正確， 以及追到的相位最終如何交給 VCO 產生實際取樣時鐘。全部公式可拖拉互動，直接看見參數改變的後果。

① 起點：相位怎麼被量出來

Mueller-Muller 相位偵測器 (MM-PD)

在談 Kp、Ki 之前，先搞懂「誤差」這個數字從哪裡來——它決定了整個迴路要去追的東西是什麼。

CDR 收到的是 PAM4 等化後的電壓樣本 x(n)，而 d(n) 是判決（slicer）後的電平（例如 PAM4 的 −3/−1/+1/+3）。Mueller-Muller 相位偵測器用「目前樣本 × 上一個判決」與「上一個樣本 × 目前判決」的差， 來估計取樣時刻偏離理想位置多少：

\( e(n) = x(n)\cdot d(n{-}1) - x(n{-}1)\cdot d(n) \)
e(n)：第 n 個符元的相位誤差（timing error）

這個式子為什麼有效，關鍵在「無 ISI（Nyquist）脈衝」的性質：如果通道響應 h(t) 在所有整數符元間距上都是 0 （只有 \( h(0)=1 \)），那麼在正確取樣時刻 \( x(n)=d(n) \)、\( x(n-1)=d(n-1) \) 完全相等， e(n) 對任何資料圖案都精確等於 0——不需要知道資料內容。這就是為什麼 MM-PD 可以在「盲」(blind) 的情況下鎖定時序。

S-curve：平均誤差 vs. 取樣相位偏移

把取樣時刻刻意偏移 τ（單位 UI），對所有可能資料圖案取平均，就得到 MM-PD 的「S-curve」timing function： \( f(\tau) \propto h(\tau - T) - h(\tau + T) \)。下圖用 β=0.3 的 raised-cosine 脈衝模型畫出這條曲線—— 它在 τ=0 準確穿越零點、且附近近似一條單調直線（不是平的，也不是亂跳的）——這代表它是一個可用的誤差訊號： 偏離零點越多，報出來的誤差量越大，符號指出偏離的方向，迴路就能靠這個方向把 τ 一路推回 0。

② 把迴路變成一個方程式

二階特徵方程式與 Kp / Ki 的由來

方塊圖上寫的 \( s^2 + K_p s + K_i = 0 \)，就是整個 PI 迴路的「身分證」——它的根（pole）決定了追蹤的快慢與是否震盪。

為什麼用二階特徵方程式？

PI 控制器有兩個狀態：比例項（看「現在」的誤差）與積分項（累積「過去」的誤差）。把 PD 誤差 e(t)、PI 輸出 pi(t)、以及回授後的相位 φ(t) 串成閉迴路，拉普拉斯轉換後分母恰好是 s 的二次式——因為一個積分器貢獻一個 s， 比例＋積分的環路剛好形成兩個狀態變數。這不是選擇，而是「比例＋積分」結構本身的數學結果： 二階是 PI 迴路能有的最低階、也是最自然的階數。

\( s^2 + K_p s + K_i = 0 \)
方塊圖上的特徵方程式（實際硬體 / Kp、Ki 的定義式）
\( s^2 + 2\zeta\omega_n s + \omega_n^2 = 0 \)
控制理論的標準二階式（ζ：阻尼比，ωₙ：自然頻率）

兩式對應係數，Kp、Ki 就直接「解」出來，不需要反覆試誤或機器學習式的訓練：

\( K_p = 2\zeta\omega_n \,,\quad K_i = \omega_n^2 \)
只要先決定「想要多快」(ωₙ) 跟「想要多穩」(ζ)，Kp/Ki 就是代數結果

Pole 的原理：震盪從哪裡來

解特徵方程式的根（pole）：

\( s = -\zeta\omega_n \pm \omega_n\sqrt{\zeta^2 - 1} \)

根號裡的 \( \zeta^2 - 1 \) 是整個故事的關鍵：

ζ 範圍Pole 型態時域行為
ζ < 1（欠阻尼）複數共軛根以阻尼頻率 ωd=ωₙ√(1−ζ²) 震盪衰減——這就是 PID 震盪的來源：Kp/Ki 相對比例不夠大，積分項的「慣性」讓追蹤衝過頭再修正，形成振鈴。
ζ = 1（臨界阻尼）重根（兩根相同）最快且不震盪的邊界。
ζ > 1（過阻尼）兩個不同實根兩個時間常數並存，較慢但單調，幾乎無振鈴。

為什麼選 ζ = 2？

上面的推導假設 PD 是「線性」的（誤差對相位成比例）。但實際硬體裡的 MM-PD 其實是 1-bit sign-sign（bang-bang）偵測器—— 只回報「早」或「晚」，不回報早/晚多少。它的等效線性增益 Kbbpd 只是對真實非線性特性的線性化近似， 會隨訊號雜訊、ISI 殘餘而變動（這也是前面 stage6_6_1 中 σeff/Kbbpd 校準要處理的事）。

選 ζ=2（而不是教科書常見的 0.707 或 1.0）的三個理由：
1. 留阻尼餘裕：即使 Kbbpd 被低估、實際有效阻尼比設計值小，迴路仍落在過阻尼區，不會翻過 ζ=1 邊界開始振鈴。
2. 降低穩態極限環 (limit-cycle) 的抖動幅度：bang-bang 迴路鎖定後會在最小步階上來回切換，阻尼越高，這個抖動的峰對峰值越小。
3. 代價是收斂變慢——下一節的響應驗證會直接量出這個代價有多大。
③ 驗證：模型說的對不對

Pulse / Step 響應驗證特徵方程式

光解方程式不夠，要把閉迴路響應算出來、看它是否符合 pole 理論的預測。

把相位偵測器到 PI 輸出視為閉迴路轉移函數：

\( H(s) = \dfrac{K_p s + K_i}{s^2 + K_p s + K_i} \)
輸入是「相位階躍」(step)，輸出是迴路追到的相位 y(t)

對單位相位階躍取拉普拉斯反轉換（部分分式展開），得到時域響應 \( y(t) = 1 + B e^{p_1 t} + C e^{p_2 t} \)， 其中 p₁、p₂ 正是上一節算出的兩個 pole。注意穩態值精確為 1（\( H(0)=K_i/K_i=1 \)）——這代表這是一個 Type-II 迴路：穩態相位誤差為零，不管 ζ 選多少都一樣，ζ 只影響「怎麼到達」1，不影響「會不會到達」1。

ζ=0.3（欠阻尼） ζ=0.707 ζ=1.0（臨界） ζ=2.0（設計值）
y(t)：追蹤到的相位 目標 = 1
一個容易忽略的細節：因為 H(s) 不是單純兩個 pole，它還帶一個零點（由 Kp·s 項造成）， 所以即使 ζ≥1（過阻尼/臨界阻尼），響應仍會有一點點過衝（overshoot）——ζ=2 時大約 4% 左右，並非完全無振鈴。 下面的圖會把這個過衝量直接讀出來，不誇大也不略過。

MM-PD 訓練、VCO 與 8-PI + DPI

把前四節串起來：PAM4 電壓 → 相位誤差 → Kp/Ki 直接計算 → pi_code → 量化成實際取樣時鐘邊緣。

MM-PD 怎麼用 PAM4 電壓把 δ 追到 0

每個符元，硬體量到等化後電壓 x(n)，slicer 判出 PAM4 電平 d(n)。 把這一筆與上一筆代入 \( e(n)=x(n)d(n-1)-x(n-1)d(n) \)，符號 sign(e(n)) 就是「早/晚」這一位元資訊。 只要迴路持續把 pi_code 往讓 e(n) 平均為 0 的方向推（也就是第①節 S-curve 的零點），取樣時刻就會 收斂到 ISI 最小、眼圖最開的位置——這就是「\( \delta \to 0 \)」的意思：δ 是「目前取樣位置」與「理想取樣位置」的相位差。

為什麼 Kp、Ki 是「直接計算」而不是「訓練」出來的

一般講「訓練」（像 DFE 的 LMS/RLS 係數）是指反覆用誤差梯度迭代逼近最佳解，事前不知道答案長什麼樣。 但 Kp、Ki 不是這樣得來的：先用通道脈衝響應（或校準量測）算出等效偵測器增益 Kbbpd， 決定想要的 ωₙ、ζ，直接代入第②節那組代數式 \( K_p=2\zeta\omega_n \)、\( K_i=\omega_n^2 \)，一步得到答案， 不需要反覆迭代收斂。「訓練」是數值逼近，「計算」是解方程式——Kp/Ki 屬於後者。

VCO + 8-PI + DPI：相位值的物理落地

VCO 由固定的參考時鐘（Ref Clk）鎖定，產生 8 個等間距的粗相位（coarse phase，每個間距 1/8 UI）—— VCO 本身不會每個符元重新調頻率，調頻率太慢也太不穩定。真正負責追蹤 pi_code 的，是數位相位插補器 （Digital Phase Interpolator, DPI）：在相鄰兩個粗相位之間，再插出 8 個細相位， 8（粗）× 8（細）= 64 個相位碼，解析度 1/64 UI。
